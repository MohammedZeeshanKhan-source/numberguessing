🎯 Number Guessing Game (Python)

A simple and interactive Number Guessing Game built using Python. The computer randomly selects a number, and the player tries to guess it within the game.

🚀 Features

Generates a random number.

Takes user input to guess the number.

Provides hints if the guess is too high or too low.

Counts the number of attempts.

Displays a winning message when the correct number is guessed.

🛠️ Technologies Used

Python 3

Random Module

Loops

Conditional Statements

User Input and Output
