# Number Guessing Game

A simple and interactive Number Guessing Game built using Python. The computer randomly selects a number, and the player tries to guess it.

## Features

- Generates a random number.
- Takes user input to guess the number.
- Provides hints if the guess is too high or too low.
- Counts the number of attempts.
- Displays a winning message when the correct number is guessed.

## Technologies Used

- Python 3
- Random module
- Loops
- Conditional statements
- User input and output

## Run

```bash
python3 game.py
```
